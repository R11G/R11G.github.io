Apply these units.csv files into War Thunder's lang folder.

# Default names
- Replaces _1 and _2 names with _shop or _0 (if _shop unavailable). This in practice applies the name shown in the kill feed to all markers regardless of range.
# Jaek898 versions
- Original localization is done by Jaek898, check out his Github for the files and more details: https://github.com/jaek898/wt-localization
- Adds missing vehicles (recently added) to the original files, using their default names and replacing _1 and _2 names with _shop or _0
